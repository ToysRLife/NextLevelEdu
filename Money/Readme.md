# 🪙 Money Market Adventure

An interactive browser-based educational game designed to teach **Money Concepts** to **Class 3 (8–9 years old)** students through everyday shopping activities.

The game follows a **learning-by-playing** approach where children buy daily-life items using Indian currency, helping them understand the value of money while having fun.

---

# 🎯 Learning Objectives

Students will learn to:

- Identify Indian coins and currency notes.
- Count money correctly.
- Make the exact amount using different combinations of coins and notes.
- Understand the value of money.
- Connect money with daily-life shopping.
- Improve addition and mental math.
- Develop decision-making skills.
- Gain confidence in handling money.

---

# 🎮 Gameplay

The player helps **Meera** purchase everyday items from different shops.

Examples:

- 🍎 Fruit Shop
- 📚 Book Shop
- 🍦 Ice Cream Cart
- ✏️ Stationery Shop
- 🧸 Toy Shop
- 🥛 Grocery Store

Every round:

1. A random shop appears.
2. A random item appears.
3. A random price is generated.
4. The child selects Indian coins and notes.
5. The game checks whether the amount is correct.
6. The child earns points.
7. A new question is generated automatically.

The game can continue indefinitely.

# 💡 Educational Philosophy

Children learn best when concepts are connected to real life.

Instead of memorizing currency values, students experience money through familiar situations like shopping for fruits, books, toys, and snacks. This approach builds confidence, improves mental math, and makes learning enjoyable.

The goal is for children to **feel like they're playing a fun shopping adventure while naturally developing essential money skills**.
