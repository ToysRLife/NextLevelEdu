# Fraction Paint & Play

An interactive browser game for Classes 1–4 that teaches fractions using colorful shapes, matching, and division grouping.

## How to run

Open `index.html` directly in a browser.

No installation, internet connection, backend, or external library is required.

## Files

- `index.html` — game layout
- `style.css` — reference-image-inspired colorful UI and animations
- `script.js` — random questions, scoring, levels, hints, painting, matching, and division grouping
- `README.md` — this guide

## What children learn

- `1/2` means 1 out of 2 equal parts
- `1/3` means 1 out of 3 equal parts
- `1/4` means 1 out of 4 equal parts
- `2/4`, `2/3`, and `3/4`
- Division means sharing objects into equal groups

## Levels

1. Easy — `1/2` and `1/4` using circles, squares, and rectangles
2. Medium — `1/2`, `1/3`, and `1/4` using triangles, rectangles, cakes, and pizzas
3. Hard — `2/3`, `2/4`, and `3/4` using mixed shapes such as stars and hexagons
4. Division Connection — object grouping such as `8 ÷ 4 = 2`

## Game modes

- Paint the Fraction
- Match the Fraction
- Division Grouping

## Controls

- Hint
- Check Answer
- Next Question
- Reset Game
