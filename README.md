# NextLevelEdu

A JavaScript-first educational game boilerplate built with Next.js App Router, Tailwind CSS, and shadcn/ui primitives.

## Development

1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Start the development server:
   ```bash
   pnpm dev
   ```
3. Run linting:
   ```bash
   pnpm lint
   ```
4. Format files:
   ```bash
   pnpm format
   ```

## Recommended Setup

- Use `pnpm` as the package manager
- Keep configuration in `.env`
- Run `pnpm prepare` after install to enable Husky hooks

## Included Features

- Next.js App Router
- Tailwind CSS
- shadcn/ui button primitive
- ESLint + Prettier
- Husky + lint-staged pre-commit support
- GitHub Actions CI
